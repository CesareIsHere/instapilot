# Esempio Finvestire

Questo è un esempio completo di brand configurato con InstaPilot per la community
educativa di finanza personale Finvestire.

## Come usarlo

1. Copia il contenuto di `brand-context.md` nel campo "Note aggiuntive" della pagina Brand Kit
2. Carica `logo.png` come logo del brand
3. Imposta i colori: primario `#012A78`, positivo `#00B373`
4. Salva e genera il primo contenuto

## File inclusi

- `brand-context.md` — documento di contesto brand completo (audience, tone, pillar tematici)
- `logo.png` — logo Finvestire (cerchio navy con F + freccia)
